# 🧁 Bakery Website

A clean and responsive bakery website designed to showcase bakery products in a simple and attractive layout.

## ✨ Features

* Responsive website layout
* Attractive bakery-themed design
* Product showcase sections
* Navigation menu
* Clean typography and spacing
* Mobile-friendly layout
* Simple and user-friendly interface

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📱 Responsive Design

The website is designed to work across:

* Desktop
* Tablet
* Mobile
